# Contributing

Thank you for helping. Before you start:

- Open an issue first for anything larger than a small fix.
- Keep changes focused; include tests (`collector/tests`, synthetic data only — never real
  accounts, logs or screenshots of a trading account).
- Sign off every commit to certify the [Developer Certificate of Origin](https://developercertificate.org/):
  `git commit -s`. Contributions are accepted under the Apache License 2.0.
- Changes to `.github/workflows`, `collector/build` or the updater get extra review.

Releases are cut by maintainers only.
